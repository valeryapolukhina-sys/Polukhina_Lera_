# Polukhina_Lera_
# Автоматизация учета и контроля за движением денежных средств в организации

Проект разработан в рамках учебной практики.

## Структура репозитория

- 1-кейс – моделирование бизнес-процессов (учет доходов и расходов)
- 2-кейс – архитектурное проектирование системы контроля ДДС
- 3-кейс – разработка интерфейса на C++ (учет финансовых операций)
- 4-кейс – организация хранения данных (базы данных, документооборот)

## Используемые технологии

- C++
- VP
- UML
- IDEF0, IDEF3, DFD
- Kaiten
